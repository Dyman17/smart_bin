# 3D-модель макета

Положите сюда исходную CAD-модель корпуса и экспортированные файлы для просмотра/печати, например `.step` и `.stl`. Физический корпус уже существует, но его CAD-файлы в исходной рабочей папке не обнаружены; в текущую поставку модель не добавлена.

Перед печатью или изменением деталей сверяйте размеры и крепления с фактическим корпусом, сервоприводами и отсеками. Никакие габариты или крепёжные размеры здесь не предполагаются.
