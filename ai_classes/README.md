# Классы ИИ

`classes.yaml` фиксирует индексы 10 классов из набора обучения, текущую конфигурацию трёх контейнеров и порог уверенности 0.55. Это справочник; работающий mapping для приложения также задаётся в `laptop_ai/config.yaml`.

`face` — отдельная модель фильтрации ложных срабатываний, а не одиннадцатый класс мусора. Лицо используется только для подавления перекрывающихся детекций и не должно давать команду на сортировку.
